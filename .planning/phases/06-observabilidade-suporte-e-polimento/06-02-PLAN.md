# 06-02: Balanceamento sem mexer em números

<objective>
Entregar duas coisas: (1) a tela da regra de recuperação (`recovery_rules`), que hoje só existe no banco; (2) um relatório de simulação que mostra, com as regras ativas, como cada inimigo se comporta contra cada classe e nível. O relatório existe para o Léo e o Miguel decidirem os números. **Esta fase não altera nenhum valor de dano, defesa ou vida.**
</objective>

<context>
- Ponto em aberto: dano 1 dos inimigos contra defesa alta; o Imp de Cinzas perde em 100% das 200 simulações com nível 3 (`STATE.md`). A decisão de números é do Léo com o Miguel.
- O motor é puro (`src/engine/combat/`) e `scripts/simulateCombat.mjs` já simula em lote no terminal; a mesma lógica roda no navegador (modo treino).
- `recovery_rules` segue o padrão das regras versionadas (`active`/`archived`, view `active_recovery_rules`, auditoria).
</context>

<tasks>

## T1 - Regra de recuperação no admin

**Type:** code
**Files:** `src/services/adminBalanceRules.js`, `src/admin/balanceView.js`, `src/admin/adminApp.js`
**Action:**
- Incluir `recovery_rules` em `ruleTables` e no menu "Balanceamento" (item "Recuperação").
- Reutilizar o editor de regra versionada: nova versão ativa arquiva a anterior; validação de JSON antes de salvar (D-31 da Fase 3).
- Mostrar em texto simples o que a regra significa (dias para regenerar, DT padrão do teste de medicina).

**Acceptance criteria:**
- Criar nova versão, ver a anterior arquivada e o registro em Auditoria.
- JSON inválido é recusado com mensagem em pt-BR.

**Verify:**
- Alterar a regra e conferir que `recover_profile` usa a versão nova (consulta SQL).

## T2 - Relatório de simulação

**Type:** code
**Files:** `src/services/adminSimulation.js`, `src/admin/simulationView.js`, `src/admin/adminApp.js`
**Action:**
- Carregar regras ativas, classes, magias e inimigos pelos serviços existentes e montar o catálogo no formato do motor.
- Matriz inimigo x classe x nível (1 a 5, configurável): taxa de vitória do jogador, rodadas médias, HP restante médio, dano médio recebido por rodada. 200 combates por célula com semente fixa (resultado reprodutível).
- Destacar células fora de faixa configurável (padrão: vitória entre 40% e 90%) e mostrar a maior fonte de dano e o menor dano causado pelo inimigo contra a defesa do alvo, para tornar visível o "dano 1".
- Execução em fatias (`setTimeout`/`requestIdleCallback`) para não travar a aba; botão cancelar.
- Somente leitura: nenhum botão salva valores. Um link leva ao catálogo de inimigos para quem for editar.

**Acceptance criteria:**
- Mesma semente gera a mesma tabela.
- A célula "Imp de Cinzas x Mago nível 3" aparece com 0% e é destacada, confirmando o ponto em aberto sem corrigi-lo.

**Verify:**
- Comparar três células com `npm run combat:sim -- --class mage --enemy ash-imp --level 3 --runs 200`.
